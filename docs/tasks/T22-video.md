# T22. Видео-демонстрация до 5 минут

**Исполнитель:** Владислав Пилипенко · **Ревью:** команда · **Приоритет:** P1
**Сроки:** сценарий — до **18.11**, видео — до **21.11** (после заморозки функций).

## Цель
По заданию видео необязательно, но приветствуется: «как студент пользуется кабинетом, в том числе с телефона». Помогает жюри по критериям К1 и К4.

## Контекст
- `task.txt` — раздел «Видео-демонстрация».
- `docs/requirements.md` §7 — что показать; `docs/contracts/seed.md` — аккаунты.

Твои файлы: `docs/process/video-script.md`.

## Что сделать
1. **Сценарий** в `video-script.md` (≤ 5 минут, по секундам):
   1. Проблема — 20 с, можно с цифрами из опроса T18.
   2. Утро студента **с телефона**: «Сегодня» → перенос пары → расписание.
   3. Успеваемость и светофор.
   4. Справка за 10 секунд: подать → скачать PDF → проверить по коду.
   5. Вопрос в деканат → **сотрудник с компьютера** отвечает и переносит пару → студент получает уведомления.
   6. Важное объявление с подтверждением.
   7. Безопасность простыми словами: второй студент не видит чужое.
   8. Финал: установка на телефон, «концепт, данные вымышлены».
2. **Запись:** телефон — встроенная запись экрана; компьютер — OBS Studio. Голос за кадром или субтитры. Только тестовые аккаунты; уведомления телефона выключить (чтобы в кадр не попали личные данные).
3. **Монтаж** в любом бесплатном редакторе; ИИ можно использовать для субтитров и озвучки — тогда указать в `docs/process/prompts.md`.
4. **Загрузка** на RuTube или VK Видео (открываются из России без VPN), доступ по ссылке. Ссылку — капитану и в `docs/progress.md` через PR.

- [ ] В кадре нет реальных персональных данных.
- [ ] Ссылка открывается без входа и без VPN (проверить с мобильного интернета).
