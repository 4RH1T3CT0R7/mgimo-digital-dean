# T13. Кабинет сотрудника: объявления и дедлайны

**Исполнитель:** Владислав Пилипенко (Codex) · **Ревью:** капитан · **Приоритет:** P1 · **Срок:** до **17.11**

## Цель
Деканат публикует новости и важные объявления для своих групп и курсов, видит, кто ознакомился (I3), и ставит дедлайны, о которых студенты получают напоминания (F5). Это идея «связи с деканатом в обе стороны» для критерия К1.

## Контекст — прочитай по порядку
1. `AGENTS.md`, `docs/tasks/README.md`, **`frontend/README.md`**.
2. `docs/contracts/notifications.yaml` — `/staff/announcements`, `/staff/announcements/{id}/acks`, `/staff/deadlines`.
3. `docs/contracts/academic.yaml` — `GET /staff/groups`, `GET /faculties` (для выбора адресата).
4. `docs/contracts/requests.yaml` — `GET /service-types` (для дедлайна «подать заявку»).
5. `docs/contracts/data-model.md` — правило Б7 (адресаты).

Твои каталоги: `frontend/src/features/staff-announcements/`, `frontend/src/mocks/handlers/notifications.ts`, `frontend/src/mocks/fixtures/notifications.ts`.

## Что сделать
1. **`/staff/announcements` — список.** Каждая строка:
   - заголовок, тип («Новость» / «Объявление»), метка «Важное»;
   - адресат текстом: «Все студенты» / «Весь факультет» / «2 курс» / «Группа МО-24-03»;
   - дата, «прочитали N»;
   - для `requires_ack` — «ознакомились N из M» (из отчёта по нажатию).

   Кнопка «Новое объявление».
2. **Форма объявления** (Sheet на телефоне, Dialog на компьютере):
   - тип (радио);
   - заголовок (3–120 символов, счётчик);
   - текст (до 4000);
   - «Важное» (чекбокс);
   - «Требует подтверждения ознакомления» — только для типа «Объявление»;
   - адресат:
     - **staff:** «Весь факультет» / «Курс» (1–6) / «Группа» (список из `GET /staff/groups`);
     - **admin:** дополнительно «Все студенты» и выбор факультета (`GET /faculties`).
   - Ошибки сервера (`details.fields`) — под полями. После успеха — тост, список обновляется.
3. **`/staff/announcements/:id` — отчёт «кто ознакомился»:**
   - объявление берётся из кэша списка; при прямом открытии загрузить список и найти по `id` (отдельного эндпоинта нет);
   - отчёт `/acks`: «Ознакомились: N из M», два списка (ФИО, группа, время) — «Ознакомились» и «Ещё нет».
4. **`/staff/deadlines`:**
   - список по сроку;
   - форма: название, описание, тип (`application` «Подача заявлений», `exam` «Экзамен», `credit` «Зачёт», `coursework` «Курсовая», `other` «Другое»), дата и время (нативные поля), услуга (только для `application`, список из `GET /service-types`), адресат — как у объявления;
   - удаление — через Dialog подтверждения (**не** `window.confirm`).
5. **Моки** для всех этих эндпоинтов, мутации в памяти. Роль в моках переключается входом под `dekanat.mo` или `admin`.
