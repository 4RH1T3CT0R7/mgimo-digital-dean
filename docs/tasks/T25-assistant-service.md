# T25. Сервис `assistant` (P2)

**Исполнитель:** Капитан (Claude Code) · **Приоритет:** P2 — только если ядро и P1 готовы к M3.

## Цель
ИИ-помощник «Спроси деканат» (I5): отвечает на вопросы о порядках и предлагает открыть нужную форму заявки. Работает на критерий К1 («смелые идеи»). Ключ LLM — только на сервере (требование задания).

## Контекст
- `docs/contracts/assistant.yaml`; `docs/security.md` §1 и §3 (ПДн не уходят в LLM).
- `content/faq.md` (T19) — база знаний.
- D16 — GigaChat или YandexGPT; при недоступности — поиск по справочнику.

## Что сделать
1. Сервис по образцу `auth`, без своей БД: справочник загружается из `content/faq.md` при старте (встроить в образ).
2. Поиск по справочнику:
   - простой рейтинг по совпадению слов (нижний регистр, без стоп-слов, грубая основа слова);
   - 3 лучших записи → `sources`.
3. LLM — если задан ключ (`LLM_PROVIDER`, `LLM_API_KEY` в `.env`):
   - системный промпт «отвечай только по выдержкам, иначе скажи, что не знаешь, и предложи „Вопрос в деканат“»;
   - в запрос — только вопрос и выдержки;
   - тайм-аут 10 с;
   - ошибка или тайм-аут → ответ из справочника (`provider = faq`).
4. `suggested_action` — если у лучшей записи есть услуга: `service_type_id` + `prefill`, если из вопроса очевидно значение поля (например, `purpose`).
5. Лимит: 20 вопросов в час на пользователя → 429.
6. В логах — только длина вопроса и провайдер, **без текста вопроса**.

## Контракты
Предоставляет `assistant.yaml`.

## Зависимости
T02; T19 (справочник); регистрация в API LLM (капитан).

## Критерии готовности
- [ ] Тесты:
  - поиск находит запись «академический отпуск» по вопросу «как уйти в академ»;
  - без ключа → `provider = faq`;
  - тайм-аут LLM → `provider = faq`;
  - 21-й вопрос за час → 429;
  - в логах нет текста вопроса.
- [ ] Ключ только в `.env` на сервере; `git grep` по ключу пуст.
- [ ] CI зелёный.

## Что не входит
История диалога, загрузка файлов, ответы по личным данным студента.
