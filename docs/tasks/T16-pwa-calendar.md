# T16. PWA и выгрузка расписания в календарь

**Исполнитель:** Всеволод Омельченко (Codex) · **Ревью:** капитан · **Приоритет:** P1 · **Срок:** до **17.11**

## Цель
Кабинет ставится на телефон как приложение, а расписание выгружается в календарь телефона (I4). Плюс к требованию «полноценно работает с телефона» (К3, К4).

## Контекст — прочитай по порядку
1. `AGENTS.md`, `docs/tasks/README.md`, **`frontend/README.md`**.
2. `docs/contracts/academic.yaml` — `GET /me/schedule.ics`.
3. `docs/security.md` — персональные данные не должны оставаться на устройстве после выхода.

Твои каталоги:
- `frontend/src/features/{pwa,calendar-export}/`;
- `frontend/public/` (иконки и манифест);
- **разрешённые правки чужих файлов:** в `frontend/vite.config.ts` — только подключение `vite-plugin-pwa`; в `frontend/src/app/` — одна строка подключения `OfflineBanner`; в `frontend/src/features/schedule/` (твой T09) — кнопка в `PageHeader.actions`.

## Что сделать
1. **`vite-plugin-pwa`.** Манифест:
   - `name` «Цифровой деканат — концепт», `short_name` «Деканат»;
   - `lang` `ru`, `start_url` `/`, `display` `standalone`;
   - цвета из токенов темы;
   - иконки 192, 512 и maskable 512 — из T17, пока их нет — простые заглушки.
2. **Service worker** — кэширует **только статику приложения**:
   - **запросы `/api/*` не кэшировать никогда** (D46: личные данные не должны оставаться в кэше после выхода);
   - `navigateFallback` → `index.html`, кроме `/api/*`.
3. **`OfflineBanner`:** при `navigator.onLine = false` — плашка «Нет соединения. Данные могут быть неактуальны».
4. **Установка:**
   - на Android/Chrome — перехват `beforeinstallprompt`, кнопка «Установить приложение» в профиле;
   - на iOS — подсказка «Поделиться → На экран «Домой»» (показывать только в Safari на iOS, если не установлено).
5. **`ExportCalendarButton`:**
   - скачивает `/api/academic/me/schedule.ics` (с сегодняшнего дня до конца семестра) через `fetch` с `credentials: 'include'` → blob → файл `mgimo-schedule.ics`;
   - рядом подсказка, как импортировать на iPhone и Android;
   - ошибка → тост с текстом.

   Кнопку поставить в `PageHeader.actions` экрана расписания.
6. **При выходе** (`logout`) очистить `caches` и `localStorage` от данных приложения — подключить через событие выхода, которое предоставляет каркас (см. `frontend/README.md`; если его нет — остановись и напиши капитану).
