# T11. Экран студента: Уведомления и дедлайны

**Исполнитель:** Владислав Пилипенко (Codex) · **Ревью:** капитан · **Приоритет:** P0 · **Срок:** до **15.11**

## Цель
Новости и объявления деканата, напоминания о дедлайнах и изменениях в одном месте (F5); подтверждение ознакомления с важным (I3). Критерии К1, К4.

## Что сделать
Все данные — через хуки TanStack Query и сгенерированный клиент `notificationsApi`; все блоки — через `QueryView`; тексты на русском.

1. **Дедлайны** — блок вверху `/notifications` (на телефоне сворачивается). Данные — `/me/deadlines?days=14`. Карточка:
   - название и описание;
   - срок «до 30 ноября, 23:59»;
   - метка `days_left`: 0 — «сегодня», 1 — «завтра», иначе «через N дней» с правильным склонением; при ≤ 1 метка красная;
   - для `kind = application` с `service_type_id` — кнопка «Подать заявку» → `/requests/new/{service_type_id}`.
2. **Лента** — `/me/feed`:
   - фильтры-чипы: «Все», «Важное» (клиентский фильтр по `important`), «Объявления» (`type=announcement,news`), «Расписание» (`schedule_change`), «Заявки» (`application_status,application_message`);
   - переключатель «Только непрочитанные» (`unread_only=true`);
   - «Показать ещё» — пагинация `limit=20` + `offset`.
3. **Элемент ленты:**
   - иконка по типу;
   - заголовок, текст (обычный текст, переносы строк сохраняются, без HTML), `author_label`;
   - время («сегодня в 10:15», «вчера», «12 ноября»);
   - точка «не прочитано»; важное выделено.
4. **Нажатие на элемент** → `POST read` и переход по `link`:
   - `application` → `/requests/:id`;
   - `lesson` → `/schedule?date=<link.date>`;
   - `none` — раскрыть полный текст.
5. **`requires_ack`:**
   - кнопка «Ознакомлен(а)» → `POST ack`;
   - после успеха вместо кнопки — «Вы ознакомились 18.11 в 10:15»;
   - до подтверждения у элемента подпись «Требует ознакомления».
6. **«Прочитать всё»** → `POST read-all`.
7. **Счётчики:**
   - хук `useFeedCounters` (`/me/feed/counters`) использует значок вкладки в оболочке;
   - после `read`, `read-all`, `ack` — **инвалидировать** ленту и счётчики.
8. **Моки:** фикстуры по `seed.md` (новости, важное объявление с `requires_ack`, уведомления о переносе и заявках, 4 дедлайна); `read`, `ack`, `read-all` меняют состояние в памяти.
