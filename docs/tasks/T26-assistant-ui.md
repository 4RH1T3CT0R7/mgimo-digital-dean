# T26. Интерфейс ИИ-помощника (P2)

**Исполнитель:** Владислав Пилипенко (Codex) · **Ревью:** капитан · **Приоритет:** P2 — только после всех своих P0 и P1.

## Цель
Экран «Спроси деканат»: студент задаёт вопрос обычными словами и сразу переходит к нужному заявлению (I5, критерий К1).

## Контекст — прочитай по порядку
1. `AGENTS.md`, `docs/tasks/README.md`, **`frontend/README.md`**.
2. `docs/contracts/assistant.yaml` — `POST /ask`, схема `Answer`.
3. T10 — форма заявки принимает предзаполнение из query-параметров (`/requests/new/:id?<ключ>=<значение>`).

Твои каталоги: `frontend/src/features/assistant/`, `frontend/src/mocks/handlers/assistant.ts`.

## Что сделать
1. **`/assistant`** (в студенческой оболочке; вход — кнопка «Спросить» на «Сегодня» добавляется **только через PR к Всеволоду**, сам не правь `features/today`).
2. Поле вопроса (3–500 символов, счётчик) и 3 примера-кнопки: «Как получить справку для военкомата?», «Как оформить академический отпуск?», «Что делать, если потерял студенческий?».
3. Ответ:
   - текст;
   - под ним — источники (заголовки записей справочника);
   - при `provider = llm` — пометка «Ответ сгенерирован ИИ и может содержать ошибки. Проверьте в деканате»;
   - при `provider = faq` — «Ответ из справочника».
4. `suggested_action` → кнопка «Заполнить заявление: <название услуги>» → `/requests/new/{service_type_id}?<prefill>`.
5. Предупреждение над полем: «Не вводите персональные данные — помощник отвечает только о правилах».
6. Состояния:
   - загрузка: «Ищу ответ…», до 10 с;
   - ошибка;
   - 429 — «Вы задали много вопросов, попробуйте через N минут».
7. Последние 5 вопросов и ответов — только в памяти страницы (**не** в `localStorage`).
8. Моки: ответы `llm`, `faq`, с `suggested_action` и без, 429.

## Обязательные тесты (Vitest + Testing Library + MSW)

| № | Проверка | Ожидаемо |
|---|---|---|
| Q1 | Ответ `provider = llm` | видна пометка «Ответ сгенерирован ИИ…» |
| Q2 | `suggested_action {service_type_id: "military-certificate", prefill: {delivery: "Электронная копия"}}` | кнопка ведёт на `/requests/new/military-certificate?delivery=Электронная+копия` (или с `%20`) |
