### 1. Сегодня (`/`)
- **Приветствие** по времени суток и имени («Добрый день, Анна») + строка «среда, 18 ноября · 12-я неделя, чётная».
- **Карточка «Сейчас / Далее»:**
  - текущая или ближайшая пара сегодня: дисциплина, время, аудитория, преподаватель, тип;
  - «идёт, до конца 40 мин» или «через 25 мин»;
  - пары закончились — «Пары на сегодня закончились» + первая пара следующего учебного дня;
  - пар нет — «Сегодня занятий нет».
- **«Изменения»:** занятия сегодня и завтра со статусом не `scheduled`, с меткой (как в расписании); нажатие → `/schedule?date=…`.
- **«Дедлайны»:** `/me/deadlines?days=7`, первые 3; «Все» → `/notifications`.
- **«Мои заявки»:** `GET /me/applications?limit=3` со статусами; нажатие → `/requests/:id`. Заявок нет — кнопка «Заказать справку» → `/requests/new/study-certificate`.
- **Важное:** если `important_unacked > 0` — заметная плашка «N важных объявлений ждут ознакомления» → `/notifications`.
- **Быстрые действия:** «Справка с места учёбы», «Расписание», «Успеваемость».
- **Каждый блок грузится и падает независимо:** если один сервис недоступен, остальные блоки работают, а у упавшего — ErrorState с «Повторить».

### 2. Расписание (`/schedule`)
- **Переключатель недели:** «‹ 16–22 ноября · 12-я неделя (чётная) ›» + кнопка «Сегодня». Неделя задаётся параметром `?date=YYYY-MM-DD`.
- **Список по дням** с закреплёнными заголовками дней; сегодняшний день выделен. Карточка занятия: время и номер пары, дисциплина, тип, аудитория, преподаватель, группа (языковая — с подписью языка).
- **Изменения — заметно, но спокойно:**
  - `moved` — акцентная метка «Перенесено с 17.11, 10:30»;
  - `moved_away` — приглушённая карточка «Перенесено на 19.11, 12:00» со ссылкой на ту дату;
  - `cancelled` — приглушённая и зачёркнутая, метка «Отменено» + причина;
  - `changed` — «Другая аудитория: 3047 (было 2105)».

  Цвет — не единственный признак: у меток есть текст (доступность).
- `AsOf` с `as_of`. День без пар — «Нет занятий»; неделя без пар — EmptyState.
- В `PageHeader.actions` место под кнопку календаря (её добавит T16).

### 3. Успеваемость (`/grades`)
- **Сводка:**
  - средний балл (`average_grade5`) и средний процент;
  - долги (красным, если > 0);
  - рейтинг: «82,5% · выше, чем у 78% курса»;
  - счётчики светофора.
- **Вкладка «Текущий семестр»** (порядок как в API — сначала проблемные). Карточка дисциплины:
  - название и форма контроля;
  - светофор: точка + текст — green «Всё хорошо», yellow «Есть риск», red «Нужно внимание»;
  - полоса «набрано `score` из 100» с отметкой `max_to_date`;
  - посещаемость;
  - `traffic_reason`;
  - строка про «отлично»: `needed = 0` → «Идёте на «отлично»»; `achievable` → «До «отлично» не хватает N баллов»; иначе — «В этом семестре «отлично» уже недостижимо»;
  - по нажатию — контрольные точки.
- **Вкладка «Сессии»** (семестры сверху вниз от последнего):
  - дисциплина, форма, часы и зачётные единицы;
  - результат: процент + оценка + буква ECTS; для зачёта — «Зачтено» / «Не зачтено»; `failed` выделен;
  - `AsOf`.
