# T15. Страница проверки справки

**Исполнитель:** Всеволод Омельченко (Codex) · **Ревью:** капитан · **Приоритет:** P1 · **Срок:** до **16.11**

## Цель
Любой, кому студент показал справку, проверяет её по коду без входа в систему. Это часть идеи «справка без очереди» (I1, критерий К1).

## Контекст — прочитай по порядку
1. `AGENTS.md`, `docs/tasks/README.md`, **`frontend/README.md`** (раздел про публичные маршруты).
2. `docs/contracts/requests.yaml` — `GET /public/certificates/{code}` (схема `CertificateVerification`, ответы 404 и 429).
3. `docs/contracts/data-model.md` — Б6.

Твои каталоги: `frontend/src/features/verify/`, плюс обработчик `/public/certificates/*` в `frontend/src/mocks/handlers/requests.ts` — **только добавить** его, остальное в файле не менять.

## Что сделать
1. **Публичные маршруты** (`publicRoutes`, без входа, без оболочки студента): простая страница с логотипом и подвалом-дисклеймером.
2. **`/verify`** — поле «Код справки» (10 символов `A–Z` и `2–7`):
   - ввод автоматически переводится в верхний регистр, пробелы убираются;
   - неверный формат — подсказка под полем, кнопка «Проверить» неактивна;
   - отправка → `/verify/:code`.
3. **`/verify/:code`** — запрос и состояния:
   - загрузка;
   - `valid = true` — зелёный блок «Справка действительна»: владелец (`holder`), факультет, название, дата выдачи, «действительна до»;
   - `valid = false` — жёлтый блок «Срок действия справки истёк» + те же данные;
   - 404 — «Справка с таким кодом не найдена. Проверьте код» + ссылка на `/verify`;
   - 429 — «Слишком много проверок. Попробуйте через N секунд» (N из `Retry-After`);
   - ошибка сети — ErrorState с «Повторить».
4. Постоянная пометка: «Демонстрационная проверка в прототипе. Справка не является официальным документом».

## Обязательные тесты (Vitest + Testing Library + MSW)

| № | Проверка | Ожидаемо |
|---|---|---|
| Z1 | Ответ `valid = true` | «Справка действительна» и `holder` |
| Z2 | Ответ `valid = false` | «Срок действия справки истёк» |
| Z3 | Ответ 404 | «Справка с таким кодом не найдена» |
| Z4 | Ввод `k7m2 qx4p7a` | в поле `K7M2QX4P7A`, кнопка активна (исправлено 09.11: в прежнем примере была цифра 9, которой нет в алфавите кода A–Z, 2–7; нашёл агент Всеволода, M13) |
| Z5 | Ввод `K7M2QX4P91` (цифра 1 недопустима) | подсказка о формате, кнопка неактивна |
| Z6 | Ответ 429 с `Retry-After: 30` | «Попробуйте через 30 секунд» |
