# T03. `pkg/events`: события через NATS JetStream

**Исполнитель:** Капитан (Claude Code) · **Приоритет:** P0 · **Веха:** M1

## Цель
Типизированная обёртка над NATS JetStream, чтобы сервисы публиковали и читали события, не собирая JSON руками (D24, AGENTS.md правило 4). Нужна для уведомлений о переносах и статусах заявок (F5).

## Контекст
- `docs/contracts/events.md` — stream, конверт, каталог событий, гарантии.
- `docs/architecture.md` §8 — несколько копий `notifications` читают как одна группа.

## Что сделать
1. Go-типы конверта и трёх событий из `events.md`, константы subjects.
2. `EnsureStream(ctx, js)` — создаёт или обновляет stream `EVENTS` с параметрами из `events.md`.
3. `Publish(ctx, evt)` — сериализует конверт; заголовок `Nats-Msg-Id = id`; `occurred_at` по Москве.
4. `Subscribe[T](ctx, durable, subject, handler)`:
   - durable-consumer с explicit ack и `max_deliver 5`;
   - ошибка обработчика → `Nak` с задержкой;
   - паника → лог + `Nak`.
5. Тесты на встроенном NATS (`nats-server/v2/test`): публикация → получение; повтор с тем же `id` не дублируется; ошибка обработчика → повторная доставка.

## Контракты
Предоставляет: Go-реализацию `docs/contracts/events.md`.

## Зависимости
T01.

## Критерии готовности

- [ ] Типы событий совпадают с таблицами `events.md` поле в поле.
- [ ] `make test`, CI зелёные.
