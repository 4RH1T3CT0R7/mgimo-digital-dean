# T23. Деплой на VPS, домен, HTTPS, резервные копии

**Исполнитель:** Капитан (Claude Code) · **Приоритет:** P0
**Сроки:** стенд — **M2 (16.11)**, прод — до **21.11**, заморозка — **22.11**.

## Цель
Прототип открывается по ссылке **из России без VPN** и работает до 28.11 (требование задания). Без этого критерий К3 обнуляется.

## Контекст
- `docs/architecture.md` §9 — эксплуатация.
- `docs/security.md` §3, §4, §6 — меры защиты и чек-лист.
- D6 (VPS в РФ), D29 (локализация данных).

## Что сделать
1. VPS у российского провайдера (Timeweb Cloud, Selectel, Yandex Cloud): 2 vCPU, 2–4 ГБ, Ubuntu LTS; домен `.ru` с A-записью.
2. Защита сервера:
   - вход по SSH-ключу, пароль отключён;
   - `ufw`: открыты только 22, 80, 443;
   - автоматические обновления безопасности;
   - отдельный пользователь для деплоя.
3. Docker + Compose; `.env` на сервере (права 600), **не в git**; случайные пароли БД.
4. Деплой:
   - `deploy/deploy.sh` — `git fetch --tags && git checkout <тег> && docker compose up -d --build && make seed` (seed только на пустую БД) + smoke-проверка;
   - выкладка **только по тегу** (`v1.0.0` и т.д.).
5. Caddy: автоматический сертификат Let's Encrypt для домена; HSTS; заголовки из T01.
6. Резервные копии:
   - `cron` — ежедневный `pg_dump` всех баз в `/var/backups/mgimo/`, хранить 7 дней;
   - **проверить восстановление** на чистой БД один раз.
7. Мониторинг доступности: бесплатный внешний пинг (российский сервис или аналог) на главную и `/api/auth/me` (401 = жив); уведомление капитану.
8. Пройти чек-лист `security.md` §6 на проде; результат — в `docs/process/security-check.md` со скриншотами.
9. **Заморозка 22.11:** последний тег, после него — только исправления критичных ошибок по согласованию команды.

## Критерии готовности
- [ ] Прод открывается по домену с мобильного интернета без VPN (скриншот с телефона).
- [ ] Сертификат валиден, `http` → `https`.
- [ ] Все 5 аккаунтов входят на проде.
- [ ] e2e (T20) зелёный с `BASE_URL` прода.
- [ ] Резервная копия снимается и восстанавливается (лог проверки).
- [ ] `security-check.md` заполнен, все пункты пройдены.
