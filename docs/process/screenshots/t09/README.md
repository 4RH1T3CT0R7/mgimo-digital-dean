Расписание открыто на `?date=2026-11-18`, чтобы показать предусмотренную seed-неделю. Главная использует настоящее время устройства, поэтому на снимке нет занятий сегодня, показан следующий учебный день. В тестах время зафиксировано на 18 ноября, 10:00 по Москве: проверены отсчёт «через 30 мин», текущая пара, завершённый учебный день.

На всех четырёх экранах `documentElement.scrollWidth <= innerWidth`. Основные кнопки, ссылки и раскрытия внутри страниц имеют высоту от 44 px. Проверены `?scenario=empty`, `?scenario=error`, `?scenario=slow` для каждого экрана: осмысленные пустые состояния, ошибки с повтором, skeleton загрузки. После задержки профиль отображает данные. Сбой только API заявок и восстановление по «Повторить» проверены через MSW в V4.

Типы, линтер, 107 тестов и production-сборка проходят. Генерация API не меняет файлы. Сборка предупреждает о едином JS-chunk более 500 kB; разделение общего роутера относится к каркасу, здесь не менялось. Проверка на настоящем API ожидает стенда.
