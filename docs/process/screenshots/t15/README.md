На 360 и 1280 px горизонтальной прокрутки нет. На всех состояниях присутствует пометка о демонстрационном документе. Форма нормализует `k7m2 qx4p7a` в `K7M2QX4P7A`; код с 1 или 9 отклоняется.

Сценарии мока для известного seed-кода `/verify/K7M2QX4PWA`: без параметров — действительная справка; `?scenario=expired`, `rate-limit`, `network`, `slow`, `empty` — соответствующие состояния. Неизвестный код, например `AAAAAAAAAA`, даёт 404. Эти переключатели реализованы только в MSW, production-компонент их не интерпретирует. Публичный мок возвращает только поля CertificateVerification, включая инициалы и факультет, без полного студенческого слепка.

Z1–Z6 (Z4 исправлен по явному согласованию пользователя) и дополнительные тесты проходят: 16 новых, всего 107 в независимой ветке. `typecheck`, `lint`, `build`, генерация API без diff — успешно. Настоящий API пока не проверялся: стенда нет.
