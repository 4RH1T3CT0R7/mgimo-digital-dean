В браузере `dekanat.mo` переносит «Теорию международных отношений» с 18.11 10:30 на 19.11 12:00–13:20. После выхода и входа как `student.mo` без перезагрузки страницы студент видит метку «Перенесено с 18.11, 10:30». Изменение живёт в памяти MSW; перезагрузка возвращает seed. Это проверка интерфейса и мока, без реального NATS и доставки уведомления. Приёмка на настоящем API ожидает стенда.

Y1–Y5 и ещё пять тестов проверяют запрос третьей пары, сводку до отправки, отсутствие кнопки у отменённого/исходного перенесённого занятия, обновление списка, 400/409, собственное время, отмену и аудиторию. Полный набор — 117 тестов, типы/линтер/сборка зелёные; генерация API без изменений.
