## Продолжение ручной приёмки, 09.11.2026 — Всеволод Омельченко

Эта запись уточняет исходный статус выше; код проверяемой сборки — `db99d5e`.

- **Установка на Windows:** настоящая кнопка профиля вызвала приглашение Chrome. Участник подтвердил «Установил»; появилось отдельное окно приложения. Снимок установленного приложения и проверка Manifest без ошибок пока отсутствуют. Установка PWA на Android не заявляется.
- **Импорт:** Google Calendar принял 137 из 137 вымышленных занятий из файла, скачанного новым UI. Снимок и SHA-256 — [в протоколе](screenshots/t16/README.md).
- **Android:** участник ответил «Да, занятия видны» после включения временного календаря и проверки недели 16–20 ноября 2026 года. Проверена синхронизация после веб-импорта; снимок телефона не получен.
- **Очистка теста:** после подтверждения Android временный календарь удалён с отдельным согласием на необратимое удаление. Google показал «Календарь удален»; строка «Тест T16 — расписание» исчезла из настроек. Другие календари не изменялись.
- **Открыто:** снимки Manifest, установленного приложения и Cache Storage после просмотра расписания и выхода; снимок календаря телефона; отдельная проверка iPhone/safe-area. Windows Computer Use снова остановился при определении URL окна, несмотря на открытый участником Manifest. Эти результаты не подменяются автотестами.

T16 остаётся черновиком до завершения обязательной ручной приёмки со снимками. Текущая правка добавляет только документацию и доказательство импорта, код и тесты не меняются.

## Продолжение: снимки участника и исправление предупреждений Manifest

- Получен снимок Application → Manifest: название, область, start_url и standalone корректны; видны три предупреждения. [Исходный кадр](screenshots/t16/manifest-before-warnings.png).
- Для расширенного окна установки добавлены настоящие превью wide/narrow. Размеры и форматы проверяются по файлам сборки; в них только вымышленные seed-данные.
- `any` и `maskable` разделены на отдельные записи одного файла 512×512. Дубликат изображения не добавлен. Статический precache включает два JPEG, API по-прежнему исключён.
- Полный снимок отдельного окна от участника визуально подтвердил установку на Windows. Для публикации нужен чистый кадр: в исходник попало постороннее уведомление с фото.
- После исправления нужны повторный Manifest, Cache Storage после выхода и снимок Android. Наличие превью не считается проверкой настоящего телефона.
