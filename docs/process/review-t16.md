Источник — [ревью PR #25](https://github.com/4RH1T3CT0R7/mgimo-digital-dean/pull/25#issuecomment-6738322029). Ручная приёмка не заменяется автотестами.

| Пункт | Результат и проверка |
|---|---|
| Сброс темы при выходе и 401 | Удалены setTheme и обход несуществующих ключей mgimo:. Cache Storage очищается, тема и чужие настройки сохраняются, в том числе при ошибке кэша. Личные запросы удаляет onLogout каркаса. |
| Офлайн-плашка и safe-area | Отступ зависит от наличия нижней навигации. На публичном входе — только safe-area, на телефоне с вкладками — высота вкладок плюс safe-area. Собственный CSS не требует изменения каркаса. Настоящий iPhone не проверен. |
| Manifest, установка, Cache Storage, импорт на телефоне | **Открыто.** Управление Chrome повторно остановилось при определении URL. Участник попросил продолжить остальные пункты. |
| Blob URL | Доступен 40 секунд после запуска скачивания и после ухода с экрана. Тест проходит до границы 39 999 мс и освобождает URL на 40 000 мс. |
| Подсказка iPhone | Указаны скачанный файл в «Файлах» и «Добавить все», если действие доступно; запасной путь — вложение в «Почте», документированный Apple. Сам импорт на iPhone остаётся открытым. |
| Одно действие — одно название | Кнопка «Скачать для календаря»; импорт описан как следующий отдельный шаг. |
| Ошибка формата | Пустой файл и неверный MIME показывают точную причину, файл не создаётся. Проверены оба случая. |
| Назначение OfflineBanner | Комментарий и README явно описывают подписки установки и очистки при выходе. |
| Постоянный role=status | Один и тот же DOM-узел при offline/online. Онлайн он пуст и скрыт, не мешает статусу загрузки. Проверены идентичность узла и видимость. |
| Установка при ошибке профиля | Раздел «Приложение» вынесен за QueryView; тест нажимает установку после ответа профиля 503. |
| Повтор includeAssets / globPatterns | includeAssets удалён, статика задаётся одним globPatterns. |
| Одинаковые иконки | Общая иконка 512×512 с purpose="any maskable", побайтный дубликат удалён; знак уже находится в безопасной области. |
| Служебный README в public | Удалён из public, описание перенесено в README фичи. |
| Цвет манифеста | theme_color теперь background светлой темы, как соответствующий meta. Принята актуальная графитовая тёмная тема из main (D55). |
| Стиль кода | Сохранены Allman и 4 пробела по прямому указанию пользователя. |
