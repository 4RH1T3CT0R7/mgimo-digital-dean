# T16: PWA и локальное хранение

`vite-plugin-pwa` 2.0.0 поддерживает Vite 8. Конфигурация — `config.ts`; цвета манифеста читаются из `src/index.css`, иконки пока содержат простой знак «ЦД» до выбора командой T17.

Service worker создаётся только при production-сборке. Он предварительно кэширует файлы сборки и не имеет правил runtimeCaching. `/api`, `/api/*` и `/api?...` исключены из навигационного fallback. MSW worker не попадает в production. В `dev:mock` PWA worker выключен, чтобы два worker не конкурировали за корневую область.

При выходе и ответе 401 обработчик `onLogout` очищает Cache Storage. Каркас удаляет личные данные из TanStack Query. В localStorage остаётся только настройка `theme`, в том числе при ошибке очистки кэша. Для загрузки учебных данных нужен интернет. После выхода первое открытие приложения без сети может не сработать, поскольку файлы кэша удалены.

Кнопка «Скачать для календаря» отправляет `fetch` с credentials include и cache no-store, задаёт сегодняшнюю московскую дату `from`, а конец семестра оставляет API. При выходе запрос прерывается, файл после выхода не создаётся. Blob URL освобождается через 40 секунд, в том числе после ухода со страницы; Safari получает время на чтение файла. Пустой ответ и неверный MIME показывают отдельную понятную ошибку. Ответ 401 завершает сессию, как сгенерированные клиенты.

В `dev:mock` экспорт формируется MSW из общего состояния расписания T14: перенос и аудитория попадают в файл, отменённые занятия и исходные строки переноса исключаются. Начало периода по умолчанию — сегодня по Москве, конец — 27.12.2026, как в seed. Production продолжает скачивать готовый файл сервиса academic.

Проверено автоматически: P1–P4, установка по событию beforeinstallprompt, Safari/iOS, установленный режим, очистка кэшей при выходе и сохранение темы при сбоях хранилища, отмена скачивания и 401. Дополнительно — кнопка с настоящим MSW, содержимое файла, фильтрация и последовательные изменения расписания. После ревью проверены установка при ошибке профиля, постоянный DOM-узел статуса, точная ошибка файла и освобождение Blob URL через 40 секунд после ухода со страницы. Всего 28 тестов T16, 166 с исправлениями полного ревью T09/T14. Обратный период экспорта возвращает пустой календарь (200), как в исправленном T04; генерация API без diff. В сборке — manifest.webmanifest, registerSW.js, sw.js, Workbox и две PNG-иконки: 512 px указан отдельными записями any и maskable с общим файлом. В манифест добавлены реальные превью расписания для wide и narrow.

Ручная проверка завершена 09.11.2026. В Chrome на Windows приложение установлено кнопкой из профиля; отдельное окно сохранено на снимке. В Manifest нет предупреждений, оба превью загружаются. После просмотра расписания и выхода на `/login` панель Cache Storage показывает «No cache storage detected». Снимки и описание перезапуска локального стенда находятся в [протоколе T16](../../../../docs/process/screenshots/t16/README.md). Установка PWA на Android не проверялась.

Файл, скачанный настоящей кнопкой из academic, импортирован в отдельный Google-календарь «Тест T16 — расписание»: **137 из 137** вымышленных занятий. Участник подтвердил, что занятия за 16–20 ноября 2026 года видны в Google Календаре на Android. Проверен путь «скачивание в браузере → импорт в веб-версии Google Calendar → синхронизация на Android»; прямое открытие `.ics` на Android не проверялось. После проверки временный календарь удалён с отдельным подтверждением участника: интерфейс показал «Календарь удален», его строка исчезла из настроек. [Протокол и снимок результата импорта](../../../../docs/process/screenshots/t16/README.md). Для получения снимка календарь был создан повторно: импортированы те же 137 событий, участник прислал настоящий Android с занятиями за 9–15 ноября 2026 года. Снимок и таблица обязательных критериев сохранены в протоколе; критерий календаря телефона закрыт.

Офлайн-плашка учитывает safe-area и наличие нижней навигации через CSS: на входе и других публичных экранах нет лишнего отступа 64 px. `role=status` остаётся в DOM; онлайн узел пуст и скрыт. Поскольку компонент подключён над маршрутизатором, он также подписывается на установку и очистку при выходе. Раздел «Приложение» в профиле не зависит от загрузки личных данных.

## Временные иконки и цвета

Иконки — знак «Мой вуз» (T17, D57), собираются скриптом `docs/brand/make-icons.ps1` из `docs/brand/logo-source.jpg`: `any` 192 и 512 px с прозрачными углами, отдельный `icon-maskable-512.png` со сплошным фоном и знаком в безопасной зоне 80 %, `apple-touch-icon.png` 180 px, `favicon.ico` (16, 32, 48 px) из центрального корпуса здания — надпись на таких размерах не читается. Иконки включаются в precache правилом `globPatterns`. Цвета манифеста берутся из светлой темы CSS; meta `theme-color` страницы также учитывает тёмную тему D55.

Итог обязательной ручной приёмки и дополнительная проверка iPhone:

1. Manifest без предупреждений и отдельное окно установленного приложения уже подтверждены снимками участника. Этот пункт ручной приёмки закрыт.
2. Проверка Cache Storage после просмотра расписания и выхода закрыта снимком: на /login кэшей нет. Протокол и исходный кадр сохранены в docs/process/screenshots/t16/.
3. Проверить переход offline/online, публичный экран входа и кнопку «Скачать для календаря» на 360 px в обеих темах; отдельно safe-area на iPhone.
4. Снимок настоящего календаря Android получен: учебные занятия за 9–15 ноября 2026 года. Все обязательные критерии ТЗ подтверждены. Прямое открытие .ics на Android и физический iPhone/safe-area отдельно не проверялись.

Источники для реализации: [Workbox generateSW](https://vite-pwa-org.netlify.app/workbox/generate-sw.html), [регистрация worker](https://vite-pwa-org.netlify.app/guide/register-service-worker), [импорт в Google Calendar](https://support.google.com/calendar/answer/37118), [руководство Apple](https://support.apple.com/guide/iphone/set-up-mail-contacts-and-calendar-accounts-ipha0d932e96/ios).

Apple документирует импорт .ics из «Почты». Путь из «Файлов» зависит от доступных действий iOS: подсказка предлагает «Добавить все» только если кнопка доступна и оставляет «Почту» запасным вариантом. Прямой импорт из «Файлов» и весь сценарий на настоящем iPhone пока не проверены.
