# База знаний помощника — инструкция для сотрудника деканата

Раздел «Помощник» в кабинете сотрудника (D66). ИИ-помощник отвечает студентам по документам из этого списка и по справочнику кабинета. Документ начинает работать сразу после добавления.

## Как подготовить документ

- **Один документ — одна тема.** «Порядок пересдач», «Стипендии», «Общежитие» — отдельными документами, а не одним сборником на 200 страниц.
- **Понятные заголовки разделов** короткой строкой: «Сроки пересдач», «Как записаться на пересдачу». Помощник ищет по словам, поэтому пишите теми словами, которыми спрашивают студенты: «пересдача», «стипендия», «справка в военкомат».
- **Конкретика:** сроки, куда подать, через какую заявку в кабинете. Чего нет в документе, помощник не придумает — он скажет, что в документах ответа нет, и предложит «Вопрос в деканат».
- **Без персональных данных:** никаких ФИО студентов и сотрудников, телефонов, номеров билетов, списков группы. Фрагменты документов уходят во внешнюю языковую модель.
- **Формат:** .docx, .txt или .md до 5 МБ, или вставьте текст. PDF не подойдёт: русский текст из него извлекается с ошибками — откройте файл в Word и сохраните как .docx. Картинки и сканы не читаются, таблицы — по ячейкам, каждая с новой строки: важное лучше написать текстом.

## Как проверить

Справа (на телефоне — под списком) — «Проверить, как ответит помощник». Задайте вопрос так, как его задал бы студент. Под ответом видно, ответила ли модель или показан фрагмент документа без ИИ, и по каким документам дан ответ.

## Выключить или удалить

- **Выключить** — документ остаётся в списке, но в ответах не участвует. Подходит для устаревшего порядка, который ещё может понадобиться.
- **Удалить** — документ и его фрагменты удаляются сразу, вернуть можно только загрузив заново.

База общая для всего вуза: документ видят все сотрудники и все студенты получают ответы по нему.
